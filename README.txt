# RIYA ROY Creation — Free Static Website Starter

This package is a working front-end/static prototype based on the agreed website structure.

## Run
Open `index.html` in a browser.

## Included
- Public browsing without forced login
- 18+ entry confirmation
- Mobile + OTP demo login
- Premium Video / Photo / Exclusive Video sections
- Membership plans
- Promotion form
- Brand Collaboration form
- Account, purchases and notifications stored in browser localStorage
- UPI intent button using the supplied UPI ID
- Demo admin statistics/order view

## Important production limitation
This is a free static build. Real automatic OTP, automatic UPI payment verification, secure membership access, server-side content protection and a real admin authentication system require a backend/payment-gateway service. The current demo intentionally does NOT pretend that localStorage or the UPI intent button is secure payment verification.

Never put UPI PIN, bank password, OTP, or payment-gateway secret keys into the website source.
